# Northstar Support Deflection MVP — Team G29

A lightweight prototype built for **Northstar Retail Co.** to deflect repetitive support tickets — reducing manual handling for **order status** and **returns/refunds** queries.

## What This Is
A chatbot/decision-tree flow that answers customer questions directly, without a human, for at least 2 of Northstar's 3 most common ticket types. Built as a 1-week MVP — not a finished product.

## Ticket Types Covered
- ✅ Order status ("Where is my order?")
- ✅ Returns & refunds ("How do I return this?")
